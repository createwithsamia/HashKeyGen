# About HashKeyGen

HashKeyGen is a simple, user-friendly, single-page web application that generates relevant Instagram hashtags and keywords based on your selected niche and post description.

### Features -
- 20 Instagram categories with 5 sub-niches each.
- Generates exactly 5 hashtags and 10 keywords.
- Simple and user-friendly interface.
- Fast, interactive, and responsive design.

### Technologies Used -
- HTML
- CSS
- JavaScript
